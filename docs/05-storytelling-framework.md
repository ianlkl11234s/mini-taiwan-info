# 05 · 敘事框架

> 每個主題都遵循同一個敘事節奏。設計師畫頁面、工程做 view、編輯寫文案都對齊這個五步走。

## 五步敘事節奏

每進入一個主題的縣市儀錶板（View B），用戶該被引導走過這五步：

```
1. HOOK     —— 一句話告訴他「這縣市這主題」的關鍵故事
2. KPI      —— 3-4 個 KPI 卡片把故事數字化
3. PATTERN  —— 一張主圖表（時序 / choropleth）讓他看到模式
4. DRILL    —— 多個 Tab 讓他往細節走（爆炸圖 + Tab 切換）
5. ACTION   —— 排名、比較按鈕、下載 CSV、跨主題連結
```

### 範例：高雄市 / 水資源

| 步驟 | 內容 |
|---|---|
| 1. HOOK | 「高雄是台灣**南部水資源最緊俏**的縣市，蓄水率全年波動最大」 |
| 2. KPI | 3 座水庫 / 12 座汙水廠 / 人均 285 L / 接管率 84% |
| 3. PATTERN | 近 30 天總蓄水率折線（顯示 4/12 跌破 30% 紅線） |
| 4. DRILL | Tab：水庫 / 水質 / 防洪 / 用水 / 排名 |
| 5. ACTION | 加入比較（→ 對比台北、台中）、下載 CSV |

## 標題寫作規範

### KPI 卡片

```
┌───────────────────────┐
│   72.3%               │  ← 主數字 32px，accent color
│   全國蓄水率           │  ← Label 14px
│   ↑ +5.2%  vs 上週     │  ← Trend 12px，正負帶顏色
└───────────────────────┘
```

- 主數字：醒目，**只有數字 + 單位**，沒有別的
- Label：說數字是什麼，**動詞名詞化**（"蓄水率" 而不是 "存了多少水"）
- Trend（選填）：與基準的比較，**永遠帶基準**（vs 上週 / vs 去年）

### 圖表標題

```
📈 高雄市近 30 天總蓄水率
   2026-04-13 ~ 2026-05-13 · 資料來源 水利署
```

- 主標：**指標 + 時間範圍 + 空間範圍**（一句話交代清楚）
- 副標：日期區間 + 資料來源 + 更新時間
- 不要用「資料趨勢圖」「圖表 1」這種廢話

### 爆炸圖標題

爆炸圖的標題格式：

```
[母 KPI 標題] · [拆分維度]
例：全國火警件數 · 按起火原因
例：高雄市水庫 · 按蓄水率排名
例：近 30 天蓄水率 · 按日
```

### Hook 寫作（要被驗證的東西）

主題 hero 上方的 hook 不能憑感覺寫，必須由資料支撐：

```yaml
# water.yaml
hook_rules:
  - condition: "max_county_lpcd / min_county_lpcd > 1.5"
    text: "用水量在縣市間差異達 {ratio} 倍，反映產業結構與供水機制差異"
  - condition: "reservoir_count_below_30pct > 3"
    text: "全國有 {n} 座水庫已跌破 30% 紅線，南部尤甚"
  - default:
    text: "全國水資源狀態目前平穩"
```

Hook 由後端依當前資料即時組裝，避免硬編碼。

## 單位 / 格式統一規範

| 類別 | 規範 | 例 |
|---|---|---|
| 大整數 | 加千分位逗號 | `123,041` 不是 `123041` |
| 百分比 | 用 `%` 符號、小數 1 位 | `72.3%` 不是 `72.3 percent` 或 `0.723` |
| 金額 | 萬 / 億 為單位（依量級） | `12.3 億` 不是 `1,230,000,000 元` |
| 時間 | YYYY-MM-DD（資料更新）/ 相對時間（剛剛 / 5 分鐘前） | `2026-05-13 10:30` |
| 座標 | 不在 UI 顯示原始座標 | 用「地址」「行政區」代替 |
| 缺失值 | 顯示 `—` 不顯示 `null` `0` `N/A` | `—（資料未開放）` |

## 顏色語意

不是隨便挑顏色：

| 語意 | 顏色 | 用法 |
|---|---|---|
| 正向 / 改善 | 綠 | 接管率上升、火警下降 |
| 警示 / 中性下降 | 黃 | 水庫跌至 50% |
| 危險 / 嚴重 | 紅 | 水庫破 30%、火警死亡 |
| 主題 accent | 各主題 yaml 指定 | KPI 主數字、主圖表線色 |
| 資料缺失 | 灰 | choropleth 上沒資料的縣市 |

正向 = 綠的判斷不是固定的：火警件數**升**才是紅。manifest 的 `ranking_better: lower` 是這類語意宣告。

## 資料來源揭露

每個圖表底部小字必含：

```
資料來源 · 更新時間 · 下載連結
經濟部水利署 reservoir_levels · 更新於 2026-05-13 10:30 · [📥 CSV]
```

點 [📥 CSV] 開新 tab 觸發下載；點來源名跳資料來源頁（彙整所有資料源的 about page）。

## 跨主題聯動敘事

「水污染裁罰 × 製造業就業」這類交叉故事，建議用 **insight card** 呈現：

```
┌────────────────────────────────────────┐
│ 💡 跨主題洞察                          │
│ ────────────────────────────────────── │
│ 高雄水污染裁罰數高於全國平均 2.3 倍，  │
│ 同時製造業就業占比達 38%，高於全國 25%。│
│                                        │
│ → 看製造業就業詳情                     │
│ → 看水污染裁罰詳情                     │
└────────────────────────────────────────┘
```

- 出現條件由 manifest 的 `crosslink` 段控制
- 不要太多，每縣市每主題最多 2 個 insight card
- 文案模板化（用變數 `{ratio}` `{n}` 填）

## 「不確定」的誠實揭露

如果指標有方法論爭議或資料限制，加注：

```
⚠️ 灌溉用水量為「18 水利會處別 → 縣市」映射估算，非官方縣市彙整
```

- 用 ⚠️ icon + 一行說明
- 點 icon 展開「資料說明」浮層
- 不要藏，藏了會被打臉

## 主題 hero（頂部敘事區）

每個主題進入 View A 時，地圖上方有 hero 區：

```
┌──────────────────────────────────────────┐
│ 💧 水資源 · 全台                          │
│ ─────────────────────────────────────────│
│ 「南北分裂的島嶼水帳」                    │
│  全國平均 LPCD 284 公升，但 22 縣市差距   │
│  最大達 1.7 倍                            │
│                                          │
│  [22 縣市著色地圖]    [全國 6 個 KPI]     │
└──────────────────────────────────────────┘
```

Hero 不長，三行字：
- 第 1 行：主題名 + 範圍
- 第 2 行：tagline（slogan-ish，主題 yaml `tagline`）
- 第 3 行：自動生成的 hook（依資料）

## 文案最後檢查清單（給編輯）

- [ ] 主標題說清楚 "什麼指標 + 什麼時間 + 什麼空間"
- [ ] 主數字格式統一（千分位、小數位）
- [ ] 趨勢箭頭永遠帶基準（"vs 上週"）
- [ ] 「資料來源 + 更新時間 + 下載」三件套齊全
- [ ] 顏色語意一致（升 = 紅 還是 紅 = 升？依主題定）
- [ ] Hook 由規則產生，不是硬寫
- [ ] 「資料未開放」優雅揭露
- [ ] 跨主題 insight 不超過 2 個 / 主題
