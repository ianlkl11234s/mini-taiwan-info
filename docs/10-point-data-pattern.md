# 10 · 點位資料設計補充（給設計師）

> 本檔是 Mini Taiwan Info 第一版 review 後的設計補充。獨立成檔，**設計師可直接以此為改稿依據**，不必讀其他規劃文件。
>
> **解決的問題**：第一版 View A 全台概覽過度仰賴 choropleth + KPI + ranking，**點位（point markers）與點位統計被低估**。本檔提出補強方案。

---

## TL;DR · 設計師需要做的 6 件事

1. ✅ **拆「圖層」UI**：把現在的「圖層 toggle」拆成「**著色指標**」+「**點位圖層**」兩段
2. ✅ **加「點位概況」面板**：在 KPI 卡片下方、Ranking 上方，加一個顯示「N 個點分布如何」的卡片
3. ✅ **加「點位散布圖」元件**：兩指標散布，每點 = 一個點位（例：水庫容量 vs 蓄水率）
4. ✅ **加「點位爆炸圖」**：點 KPI 「40 座水庫」⤴ 展開**全部 40 座個別狀態**
5. ✅ **設計縮放級別點位行為**：不同 zoom level 切換 cluster / heatmap / 著色點 / 點+label
6. ✅ **設計點位 popup**：點任一點位時的浮層內容規格

---

## 1. 問題現況

### 第一版 View A 截圖診斷

第一版有兩個主要視覺資產：
- 左側 22 縣市 choropleth（縣市總體）
- 右側 6 個 KPI + ranking（縣市總體）

兩者都是「**縣市彙整數字**」。但水資源、火災、社會經濟主題的真實故事**藏在點位**：

| 主題 | 縣市彙整看得到 | 縣市彙整看不到（在點位裡） |
|---|---|---|
| 水資源 | 全國蓄水率 72.3% | 翡翠 95% vs 阿公店 28% 的南北分裂 |
| 火災 | 全國平均到場 4.3 分鐘 | 茂林萬山里距分隊 18 km 的服務盲區 |
| 社會經濟 | 房價中位 38.5 萬/坪 | 信義 138 萬/坪 vs 三民 28 萬/坪 的城內落差 |

**結論：把點位當成「裝飾」是失誤；點位是水資源/火災主題的敘事主角。**

## 2. 點位資料 vs 統計資料的分工

設計上要把兩種資料明確分開呈現，**不要混在一起**：

```
┌─────────────────────────────────────────────────────┐
│  統計資料（縣市彙整數字）                            │
│  ───────────────────────────                        │
│  ✓ Choropleth 著色                                  │
│  ✓ KPI 卡片                                         │
│  ✓ TOP / BOTTOM ranking                             │
│  ✓ 縣市別長條圖                                     │
│  ─────────────────────────────────────              │
│  問：「縣市之間誰高誰低」「全國趨勢如何」           │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  點位資料（每個物件一個位置 + 屬性）                 │
│  ───────────────────────────                        │
│  ✓ 點位圖層（地圖上的點/圓/icon）                   │
│  ✓ 點位概況面板（N 個分布如何）                     │
│  ✓ 點位散布圖（兩指標 × N 點）                      │
│  ✓ 點位 cluster 統計                                │
│  ✓ 服務圈 / 緩衝圈                                  │
│  ─────────────────────────────────────              │
│  問：「具體哪幾個」「分布在哪」「個別狀態如何」     │
└─────────────────────────────────────────────────────┘
```

兩種視角同時提供，用戶可以從「縣市」進入後「**點開看點位**」。

## 3. View A 左側地圖：圖層 UI 重設計

### 現況（第一版）

```
┌──── 圖層 ────────────────┐
│ ☑ 蓄水率                 │
│ ☐ 24hr 均雨量             │
│ ☐ 高警戒水庫              │
│ ☐ 淹水高潛勢區            │
└──────────────────────────┘
```

⚠️ 問題：這 4 個都是 choropleth 著色選項，不是真的「圖層」。「高警戒水庫」其實該是個點位層，但混在一起了。

### 建議改成兩段式

```
┌──── 著色指標 ────────────────────┐
│ ● LPCD（人均日用水）  預設       │
│ ○ 蓄水率                          │
│ ○ 接管率                          │
│ ○ 水污染裁罰                      │
│ ○ 淹水高潛勢面積                  │
│  ─── 切換為連續色階 ────          │
└───────────────────────────────────┘

┌──── 點位圖層 ──────────────────────┐
│ ☑ 🔵 40 座主要水庫    按蓄水率   │
│ ☐ 🟢 242 雨量站       按 24hr 雨 │
│ ☐ 🟣 1,201 水質測站   按 BOD/DO  │
│ ☐ 🟡 188 河川水位站                │
│ ☐ 🔴 列管事業         環境部 45174 │
│ ☐ ⬛ 82 汙水處理廠                  │
└─────────────────────────────────────┘
```

### 視覺規格

- **著色指標**：radio（單選），有「目前選中項」明確視覺暗示
- **點位圖層**：checkbox（多選），每項前面有 **顏色 dot + 點數**
- 兩段之間有 visual divider
- 可摺疊（預設展開）

## 6. 縮放級別的點位行為

點位太多會視覺爆炸 → 必須依 zoom level 切換呈現：

```
全台 zoom 5-7  ──→  cluster 圓圈（內含數字）+ heatmap 底
                    ╱
縣市 zoom 8-10  ──→  完整點位 + 著色（不顯示 label）
                    ╱
鄉鎮 zoom 11-13 ──→  完整點位 + 著色 + 「主要點位 label」
                    ╱
建築 zoom 14+   ──→  完整點位 + 著色 + 全部 label + 預設 popup
```

### Cluster 圓圈視覺規格

```
   ┌──┐
   │24│   ← 數字（總點數）
   └──┘
    └─ cluster 圓圈，依範圍大小分 3 級：
       Lv1 (10-50)  半徑 16px  顏色 50% 飽和
       Lv2 (51-200) 半徑 22px  顏色 70% 飽和
       Lv3 (200+)  半徑 28px  顏色 100% 飽和
```

點 cluster → zoom in。

### Heatmap 底色

當點數 > 500 時，**zoom 5-9 顯示 heatmap 底**，淡色徑向漸層。

## 7. 點位 Popup 規格

點任一點位時：

```
┌──────────────────────────────────┐
│ 🔵 翡翠水庫                       │
│ 新北市 · 1987 啟用                 │
│ ──────────────────────────────── │
│ 蓄水率       95.3%  🟢            │
│ 水位         165.32 m              │
│ 有效蓄水    311.5 萬 m³           │
│ ──────────────────────────────── │
│ 📈 看 30 天趨勢   📋 看完整資料  │
└──────────────────────────────────┘
```

### Popup 結構（給所有點位類型用）

1. **Header**：圖示 + 名稱 + 地點/類別
2. **Key Stats**：3-5 個關鍵數字（用顏色標警示）
3. **Actions**：1-2 個 CTA 按鈕（連 View C 詳情頁 / 看時序圖）

### Popup 互動

- 點地圖空白 → 收起
- ESC → 收起
- 點 popup 外的另一點 → popup 跟著切
- 手機上 → popup 改為下方 sheet

## 8. 點位爆炸圖（新增第四種爆炸模式）

原規劃有三種爆炸（維度/時間/空間），**漏了第四種**：**點位爆炸**。

點 KPI 卡片「40 座主要水庫」上的 ⤴ → 展開**全部 40 座個別資訊**：

```

│                                        │
│  🔴 阿公店   28.3%  18 萬 m³  高雄    │
│  🔴 烏山頭   25.9%  73 萬 m³  台南    │
│  🔴 永和山   29.2%  ...                │
│  🔴 鯉魚潭   29.8%  ...                │
│  🟡 曾文     33.3%  595 萬 m³ 嘉南    │
│  🟡 ...                                │
│  🟢 翡翠     95.3%  327 萬 m³ 新北    │
```

### 點位爆炸的三種排序

- **按指標**：蓄水率高→低 / 低→高

設計上用 chip toggle 切換。

## 10. 邊界情境處理

### 點位密度極高（消防栓上萬）

- 必開 heatmap + cluster
- zoom 出去隱藏點位、只看 heatmap
- 圖層 toggle 加「顯示 heatmap」副選項

### 點位密度極低（離島某縣只有 1-2 點）

- 不做 cluster
- 點旁邊直接 label
- 「資料未開放」狀態出現時：顯示淡灰色 placeholder

### 該縣市完全無此類點位（例：澎湖無水庫）

- 圖層 toggle 該項標灰 + tooltip：「澎湖縣無水庫資料」
- 右側「點位概況」面板顯示「該縣市無此類資料」+ 連結「→ 看全國 N 座分布」

## 11. 顏色與符號規範

### 點位顏色語意（跨主題統一）

| 色 | 語意 | 例 |
|---|---|---|
| 🟢 綠 | 正常 / 充足 / 安全 | 蓄水率 60%+、學校充足 |
| 🟡 黃 | 警示 / 中間 | 蓄水率 30-60% |
| 🔴 紅 | 危險 / 嚴重 / 違規 | 蓄水率 <30%、火警致死、違規列管 |
| 🔵 藍 | 主題基準色（水） | 一般水庫、雨量站 |
| 🟣 紫 | 第二語意（測量） | 水質測站、學校 |
| 🟠 橙 | 第三語意（風險場所） | LPG、危險物品 |
| ⬛ 灰 | 中性 / 設施 / 無資料 | 汙水廠、無狀態 |

### 點位符號（icon shape）

| 形狀 | 用途 |
|---|---|
| ⚫ 實心圓 | 一般點位（測站、機構） |
| 🔘 環形圓 | 重點點位（水庫、主要設施） |
| ▲ 三角 | 風險警示（危險物品、LPG） |
| ⬛ 方形 | 行政設施（消防分隊、警察） |
| ◆ 菱形 | 緊急設施（避難所） |
| 🏥 lucide icon | 特定主題（醫院、學校） |

**規則**：同一主題下符號要一致，避免設計師為每個資料集找新 icon。

## 13. 不是這個版本要處理的事

避免一次塞太多：

- ❌ 點位的時間動畫（例：水庫蓄水率 30 天回放）→ Phase 2+
- ❌ 點位連線（例：消防分隊 → 救護路徑）→ Phase 3+
- ❌ 3D 點位（例：建築物高度）→ 不做（已聲明不要 3D）
- ❌ 點位 AR / VR → 不做
