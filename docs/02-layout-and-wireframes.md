## 響應式設計（Mobile）

```
┌──────────────────────────┐
│ TOP BAR (compact)        │
│ 💧 水 ▾   2024 ▾   ⋯    │
├──────────────────────────┤
│                          │
│      [MAP] ~40vh         │
│                          │
├──────────────────────────┤
│  ↕  (drag to expand)     │
│                          │
│   DASHBOARD (scrollable) │
│                          │
│   KPI 卡片改成 2x2 grid  │
│   ranking 改成下拉折疊   │
│   Tab 變成水平 scroll    │
│                          │
└──────────────────────────┘
```

- 手機優先設計圖表：**單欄 KPI 卡片 + 摺疊式表格**
- 地圖 + 儀錶板**上下 sheet**，可上滑全屏儀錶板（地圖縮到頂部 tab）
- 爆炸圖在手機改成**全屏 modal**

## 暗色模式

不是核心需求，但建議**從一開始預留**（用 CSS variables `--bg-primary` / `--text-primary` / `--map-tile-style`）。地圖底圖 Mapbox / MapLibre 有 dark theme tiles，切換成本低。

## 視覺尺寸建議（給設計師）

| 元素 | 尺寸 |
|---|---|
| 主版面最小寬度 | 1280px（小於改成 mobile 版） |
| 地圖左欄 | 52% (~665px) |
| 儀錶板右欄 | 48% (~615px) |
| KPI 卡片 | 1/3 寬 × 110px 高（桌機 3 卡並排）|
| Tab bar 高度 | 48px |
| 主題切換器（底部） | 56px |
| 字體 | 14-16px 正文、24-32px KPI 數字、12-13px metadata |

更詳細的 hi-fi 由設計師主導；本檔給出**結構與比例的硬約束**。
