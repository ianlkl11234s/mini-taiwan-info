## 地圖 layer 設計（重要）

無論 View A 還是 View B，地圖上**始終顯示 2 個基礎 layer**：

| Layer | View A 全國 | View B 縣市 |
|---|---|---|
| ● **消防分隊點** | 全 22 縣市分隊（~629 個紅 dot） | 該縣市分隊（放大，含名稱標籤） |
| 🔥 **火災熱點圖** | 全國個案 heatmap（48,657 點，聚成熱區）| 該縣市個案 heatmap（密集細節）|

**可 toggle 的 layer**（user 自由開關）：

| Layer | 適用 view | 備註 |
|---|---|---|
| 💧 消防栓 | View B 限 4 都 | 北/中/南/高 only，其他標 ⚠️ |
| 🏥 急救醫院 | 全 | 雲林 only，其他 placeholder |
| ▒ 林火風險熱區 | 全 | snapshot |
| ~~🌋 火山潛勢~~ | — | ❌ 2026-05-15 移 Backlog |

**著色 choropleth**（背景，22 縣市）：

預設用「火災密度 per 萬人」（reds ramp），可切換為：
- 分隊密度 / 萬人（reverse ramp）
- 5min 圈外人口比 / %
- 消防栓密度 / km²（4 都 only）

# KPI 爆炸視圖（4 區塊每個 KPI 卡都通用）

點任一 KPI 卡 → 進入爆炸大圖：

```
┌──────────────────────────────────────────────────┐
│ ← 返回          年度火災件數                     │
├──────────────────────────────────────────────────┤
│                                                  │
│ [時間 scale]                                     │
│  ⦿ 年（10 年柱）  ○ 月（12 月柱）               │
│  ○ 日（365 折線）  ○ 時段（24h 柱）             │
│                                                  │
│ [維度切換]                                       │
│  ⦿ 全國總和  ○ by 縣市  ○ by 5 大類原因        │
│  ○ by 場所  ○ by 死傷嚴重度                    │
│                                                  │
│  ┌────────────────────────────────────────┐     │
│  │   (大圖：bar / line 動態切換)          │     │
│  │                                        │     │
│  │     ▮▮▮▮▮▮▮▮▮▮▮▮▮                    │     │
│  │  ▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮▮                  │     │
│  │ 104  105  106  ...  113  (民國年)      │     │
│  └────────────────────────────────────────┘     │
│                                                  │
│ [關聯爆炸]                                       │
│  點某一柱 → 進該年的細部（by 原因 / by 縣市）  │
│                                                  │
│ [下載] CSV / JSON                                │
└──────────────────────────────────────────────────┘
```

**規格細節**：
- 上方 2 行 radio button（時間 scale × 維度）兩兩組合 → 20 種大圖切換
- 大圖**圖型依 scale 自動切換**：年/月/時段 → bar；日 → line
- **維度切到「by 縣市 / by 原因 / by 場所」** → 大圖變堆疊 bar（時間 x 軸 + 維度 stack）
- click 大圖某一柱 → 進二級爆炸（該年該縣市 by 原因，或該原因 by 縣市）
- 4 個 KPI 卡都套此模式（年度件數 / 死傷 / 財損 / 主因佔比），維度選項略有不同

**為什麼補**：你拍板 3「KPI 預設最新 + 時間軸切換」需要這個爆炸介面，要寫清楚怎麼切換、切換後長什麼樣。
