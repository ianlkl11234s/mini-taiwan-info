# 主題詳規 · 🏠 首頁基礎統計（home-basics）

> Mini Taiwan Info 的「**首頁主題**」。用戶開站第一眼看到的就是這個。
> 數值核心 = 內政部統計處戶政月報；互動鑽取 = TGOS 內政主題 API。

---

## 🚨 重要前提：TGOS MOI API 的真實能力

TGOS 內政主題 API（`data.tgos.tw/MOIDataThemeAPIMgr`）**不是統計 API**，它是：

| 提供 | 不提供 |
|---|---|
| ✅ 點地圖 → 行政區反查（縣/鄉/村） | ❌ 縣市人口統計 |
| ✅ POI 主題分布（學校、醫院、加油站…） | ❌ 老化指數、扶養比 |
| ✅ 圈選範圍找 POI（Buffer） | ❌ 出生死亡時序 |
| ✅ 地址 / 郵遞區號工具 | ❌ 移入移出資料 |

所以本主題的資料源是**兩個來源混搭**：

```
數值統計          ──→  內政部統計處戶政月報 (data.gov.tw + CSV/API)
互動 + 邊界鑽取    ──→  TGOS MOI API (.env: TGOS_MOI_API_KEY)
POI 分布           ──→  TGOS MOI API
```

## 主題定位

**「打開網站第一眼看到的台灣 vital signs」** — 不深入任何專業領域，給用戶一個全島基礎輪廓：人口、行政區、年齡組成、生老病死。

任何用戶從這裡開始：
- 想了解某縣市 → 點地圖進入該縣市的 home-basics 細項
- 想看專題 → 切下方主題列到水資源 / 火災 / ...

## View A · 全台概覽

### 全國 KPI 卡片（6 個）

| # | 指標 | 單位 | 來源 | 爆炸圖 |
|---|---|---|---|---|
| 1 | 全國人口 | 人 | 戶政月報 | 維度（縣市分布）+ 時間（近 10 年） |
| 2 | 縣市數 | 個 | 行政院主計處 | （無爆炸）|
| 3 | 鄉鎮市區數 | 個 | 內政部行政區資料庫 | 維度（縣市內分布） |
| 4 | 村里數 | 個 | segis | 維度（縣市內分布） |
| 5 | 年出生率 / 死亡率 | ‰ | 戶政月報 | 維度（縣市對比） + 時間（近 10 年） |
| 6 | 老化指數 | % | segis / 戶政月報衍生 | 維度（縣市 + 鄉鎮）+ 時間 |

### Choropleth 預設指標

**老化指數**（65+ 歲人口 / 0-14 歲人口 × 100）—— 視覺差距大、有政策意涵。可下拉切換為「總人口」「人口密度」「年增率」。

### 自動產出的 hook 文案

```yaml
hook_rules:
  - condition: "max_county_aging / min_county_aging > 2"
    text: "全台老化指數縣市差距達 {ratio} 倍 — 從 {min_county}（{min_value}）到 {max_county}（{max_value}）"
  - condition: "national_population_yoy < 0"
    text: "全國人口連續 {n} 個月負成長"
  - default:
    text: "全國人口 {total} 人 · 22 縣市 · {town_count} 鄉鎮市區 · {village_count} 村里"
```

## View C · 資料集深入

### Demo 1 · 點某 POI 看詳細

點高雄市某學校（如「高雄中學」）→ 進詳情頁：
- 地址 / 郵遞區號（`/Zip33/Addr`）
- 學校類型 / 學生人數（需另接教育部資料）
- 周邊 1km 內其他 POI（`/Theme/Buffer`）

### Demo 2 · 點某縣市看人口時序

點高雄市總人口 KPI → 進詳情頁：
- 近 30 年人口變化折線
- 各鄉鎮人口分布表
- 年齡組成歷年熱力圖
- 來源：戶政月報

| home-basics 指標 | 對接主題 | 故事 |
|---|---|---|
| 老化指數 | 醫療 | 老人 vs 醫療點密度 |
| 出生率 | 社會福利 | 出生率 vs 托嬰中心覆蓋 |

## 資料源整理

### Layer 1 (Supabase) - 需建表

| 表 | 來源 | 頻率 |
|---|---|---|
| `demographics.population_by_county_monthly` | 戶政月報 | 月 |
| `demographics.population_pyramid_by_county_yearly` | 戶政月報衍生 | 年 |
| `demographics.aging_index_by_county_yearly` | segis | 年 |
| `admin.counties` / `townships` / `villages` | 內政部行政區 / NLSC | 不定期 |

### Layer 3 (TGOS) - 直接呼叫

- `/Theme/List` 取得 POI 主題列表（學校 / 醫院 / ...）
- `/Theme/Query?County=...` 縣市 POI
- `/Range/Administrative` 邊界反查
- `/Zip33/*` 地址工具

### Layer 4 (外部直抓 / 月度同步)

- data.gov.tw 戶政月報 (datagov:可查內政部統計處)
- segis 行政區人口指標
