  2️⃣ 每個 session 的實驗結果 → .claude/board/*.md(已 commit,這就是你問的)

  每跑一個 tmux session 就留一份 board,共 20
  份:過夜的(etl_fire/maritime/water…)、SEGIS(etl_demog_114)、稽核(audit_*)、修復(batch1/2)、能力探測(probe_mini/analytics)、貓纜根治(etl_cable_fix)…
  每份記:做了什麼/改哪些檔/驗證/commit hash。

  3️⃣ 即時進度/總覽 → .claude/ 根目錄(已 commit)

  - WAVE_REPORT.md ← 每個 Wave/Batch 一句話總結(主報告)
  - AUDIT_MASTER_PLAN.md ← 全主題稽核 + 修復批次計畫
  - SESSION_BOARD.md ← 跨 session 進度看板

  4️⃣ 工作檔(prompt/queue/中間產物)→ .claude/tmp/(未入 git,可丟)

  每個 session 的 prompt 原文(prompt_*.txt)、過夜佇列、recon/done 中間報告。
